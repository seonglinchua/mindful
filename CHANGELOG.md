# Changelog

## 0.1.0 — MVP

### Added

- Guided 4–4–6 breathing with session presets, looping, pause, resume, reset, progress, and remaining time
- Daily mood check-ins with streak, average mood, and seven-day history
- Autosaved daily intentions and locally stored reflections
- Reflection editing, deletion, and undo recovery
- Responsive desktop and mobile layouts
- Keyboard focus, live status messages, semantic control states, and reduced-motion support
- Static export and GitHub Pages deployment workflow

### Privacy

- Personal wellness data remains in browser `localStorage`
- No account, server-side data store, analytics, or network API is required
